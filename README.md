# Футбольные крестики-нолики

Учебная версия крестиков-ноликов 3×3 на PyQt6. По краям поля — шесть случайных европейских клубов из десятки. Клетка — пересечение клуба строки и клуба столбца. Две команды, «Хозяева» и «Гости», ходят по очереди.

Проверка «играл ли названный футболист за оба клуба» пока случайная (да/нет). Настоящая база игроков не подключена.

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m football_ttt
```

То же самое: `python main.py`.
