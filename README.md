# Футбольные крестики-нолики

Учебная версия крестиков-ноликов 3×3 на PyQt6. По краям поля — шесть случайных европейских клубов из десятки. Клетка — пересечение клуба строки и клуба столбца. Две команды, «Хозяева» и «Гости», ходят по очереди.

Проверка ответа — агент в `football_ttt/agent`. Строка из поля уходит в локальную модель, она достаёт имя футболиста. Имя вместе с двумя клубами клетки передаётся в функцию, которая читает карьеру на странице игрока в английской Википедии. Клетка закрашивается, только если в карьере есть оба клуба.

При первом ответе модель скачивается в `~/.cache/football-ttt` (около 1 ГБ).

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m football_ttt
```

То же самое: `python main.py`.
